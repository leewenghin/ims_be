# Backend v1.0: Testing and Hardening

## Goal
Prove the important rules with automated tests, then tidy up the rough edges so the backend is "release" quality.

## Prerequisites
Backend v0.8 is done.

## Test types

| Type | Annotation | Speed | Use for |
|---|---|---|---|
| Unit | none (`@ExtendWith(MockitoExtension.class)`) | ms | Service rules with mocked repositories |
| Repository slice | `@DataJpaTest` | ~1 s | Custom JPQL, constraints, Specifications |
| Web slice | `@WebMvcTest(Controller.class)` | ~1 s | Validation, status codes, JSON shape |
| Integration | `@SpringBootTest` + `@AutoConfigureMockMvc` | a few s | Full flows with security and the real database |

In Boot 4 the test annotations moved into the new test modules (`spring-boot-starter-webmvc-test`, `spring-boot-starter-data-jpa-test`). Let your IDE import them; don't copy package names from Boot 3 tutorials.

## Must-have tests

### `StockMovementServiceTest`
- An issue larger than the stock throws `InsufficientStockException`, and nothing is saved (`verify(movementRepo, never()).save(any())`).
- A receipt on a missing stock level creates a level with the received quantity.
- An adjustment computes `delta = counted - current`; a delta of 0 throws.
- A transfer creates an OUT and an IN with the same `transferId`, and rejects from == to.
- `balanceAfter` equals the new level quantity.

### `StockLevelRepositoryTest`
- Saving two levels for the same (branch, product) throws `DataIntegrityViolationException`.
- Forcing a negative quantity through a native update violates the check constraint.
- The `lowOnly` query returns only items at or below the reorder level.

### `ProductControllerTest` (`@WebMvcTest`, service is mocked with `@MockitoBean`)
- A POST with a blank name returns 400 with `errors.name`.
- A service `NotFoundException` becomes a 404 `ProblemDetail`.
- Security is part of the web slice. Use `.with(jwt().authorities(new SimpleGrantedAuthority("ROLE_ADMIN")))` from `spring-security-test`.

### `AuthIntegrationTest`
- Logging in as the seeded `admin` returns 200 and a token. A bad password returns 401.
- With no token, `/api/products` returns 401.
- `staff` receiving at PG01 returns 403, and `staff` adjusting returns 403.

### `StockFlowIntegrationTest`
- Receive, issue, transfer, then `GET /api/inventory` shows the expected numbers.
- **Ledger invariant**: after the flow, for every stock level, `sum(quantityDelta)` equals `quantity`.
- Concurrency (optional, but very instructive): two threads each issue 6 from a stock of 10. Exactly one succeeds, and the final quantity is 4.

Use `@Transactional` on the test class only for tests that don't depend on commits. The concurrency and audit `REQUIRES_NEW` tests need real commits, so reset with `@DirtiesContext` or clean-up methods instead.

## Hardening checklist
- [ ] **Secrets**: `app.jwt.secret` comes from the `JWT_SECRET` environment variable outside dev; the default value only exists in a `dev` profile.
- [ ] **Profiles**: `application-dev.yml` holds H2 console, `show-sql`, and seed `true`. The default profile has these off.
- [ ] **Paging limits**: `spring.data.web.pageable.max-page-size: 100`.
- [ ] **Validation review**: every request DTO has `@Valid` on the controller parameter, and every string has a `@Size` that matches its column length.
- [ ] **Errors**: there's no stack trace in any response (`server.error.include-stacktrace: never`), and every error is a `ProblemDetail`.
- [ ] **N+1 queries**: turn on `show-sql`, call `GET /api/inventory` and `GET /api/movements`, and make sure you see a small, fixed number of queries. Fix any problems with `join fetch` or `@EntityGraph`.
- [ ] **Indexes**: every column you filter on has an index (check the `CREATE INDEX` statements in the startup log).
- [ ] **Logging**: log one line per movement at INFO level (`movement type=ISSUE branch=KL01 sku=SKU-002 delta=-3 by=staff`), and never log passwords or tokens.
- [ ] **Swagger**: each controller has a `@Tag`, and the bearer auth button works.
- [ ] **Persistence option**: try `jdbc:h2:file:./data/ims` with `ddl-auto: update`, restart, and confirm the data survives and the seeder skips.
- [ ] `.\gradlew.bat clean build` is green.
